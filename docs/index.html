How it works

Four steps. No admin keys.

A vault is a self-contained contract. Anyone can deploy one. Once deployed, no one — not the team, not the DAO — can change its rules.

1

Deploy

Anyone calls the factory with a token address and a tax config. A new vault is cloned via EIP-1167 in a single transaction.

2

Deposit

Users deposit the underlying token. A tax (e.g., 5%) is taken. Shares are minted pro-rata to the net amount.

3

Accrue

The tax is split: dividends flow to existing shareholders, 0.5% to the protocol treasury, remainder burned forever.

4

Claim & exit

At any time, claim your share of the dividend pool. Exit with the redeem flow — exit tax applies, more dividends accrue, more tokens burn.
