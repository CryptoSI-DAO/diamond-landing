Why the SVG won by default:

  • Vector: scales to any size (16px favicon → 4K social banner) without quality loss. AI generations are 512×512 PNG and degrade when scaled up.
  • Theme-aware: the SVG uses currentColor so the D cutout adapts to dark/light mode automatically. AI images are fixed.
  • Editable: anyone with a text editor can tweak the gradient stops, swap the D for a different letterform, or adjust the chevron. AI images require Photoshop or a designer.
  • File size: 836 bytes vs 10–20KB per PNG variant.
  • Designer-quality output: AI image generators are great for mood boards but rarely produce logo-quality output (issues with edge cases, type, consistency, legibility at small sizes).

If you want to iterate on the AI variants: hit bash scripts/regen-logos.sh with a new prompt, or open this page in a browser and use the prompts above in Midjourney / DALL-E / Ideogram (those are higher quality than free-tier Pollinations).
